# Global Rules and Policies

This directory contains system-wide rules, policies, and standards that apply across all agents and workflows.

## Overview

Global rules ensure consistency, quality, and coordination across the entire agent workflow system.

## Core Principles

### 1. Collaboration First
- Agents must communicate clearly
- Handoffs must be explicit
- Dependencies must be documented
- Blockers must be raised immediately

### 2. Quality Over Speed
- Never compromise quality for timeline
- All work must be reviewed
- Testing is mandatory
- Documentation is required

### 3. Transparency
- All decisions documented
- Status always up-to-date
- Issues communicated promptly
- Progress visible to all

### 4. Continuous Improvement
- Learn from each workflow execution
- Update rules based on experience
- Share learnings across teams
- Regular retrospectives

## Universal Standards

### Documentation
- All documents in Markdown
- Version controlled
- Clear naming conventions
- Regular updates

### Communication
- Response time: 24 hours max
- Critical issues: Immediate
- Status updates: Daily
- Clear, concise language

### Quality Gates
- Code review required
- Testing required
- Documentation required
- Approval required

### Versioning
- Semantic versioning (major.minor.patch)
- Change logs maintained
- Backward compatibility considered
- Deprecation notices provided

## Enforcement

These rules are enforced through:
- Workflow checkpoints
- Automated validation where possible
- Peer review
- Regular audits

## Exceptions

Exceptions to global rules require:
1. Written justification
2. Risk assessment
3. Approval from responsible agent
4. Documentation of the exception

## Updating Rules

To propose rule changes:
1. Document the proposed change
2. Explain the rationale
3. Assess impact
4. Get consensus from affected agents
5. Update documentation
6. Communicate changes
