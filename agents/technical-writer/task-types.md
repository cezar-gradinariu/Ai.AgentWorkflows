# Technical Writer Agent Task Types

## Task Types the Technical Writer Agent Can Handle

### 1. Write User Guide
**Description**: Create comprehensive user documentation
**Input Required**:
- Feature specifications
- UI screenshots
- User workflows
- Target audience

**Output Produced**:
- User guide document
- Screenshots and diagrams
- Step-by-step instructions
- Troubleshooting section
- FAQs

**Typical Duration**: 1-3 days

---

### 2. Write API Documentation
**Description**: Document REST APIs or GraphQL endpoints
**Input Required**:
- API specifications
- Endpoint details
- Authentication methods
- Example requests/responses

**Output Produced**:
- OpenAPI/Swagger spec
- API reference documentation
- Authentication guide
- Code examples
- Error reference

**Typical Duration**: 1-2 days

---

### 3. Create Quick Start Guide
**Description**: Write concise getting-started documentation
**Input Required**:
- Product overview
- Setup requirements
- Basic workflows
- Common tasks

**Output Produced**:
- Quick start guide
- Installation steps
- First-use tutorial
- Essential features overview

**Typical Duration**: 4-8 hours

---

### 4. Write Technical Specification
**Description**: Document technical architecture and design
**Input Required**:
- Architecture diagrams
- Technical design documents
- Component interactions
- Technology stack

**Output Produced**:
- Technical specification document
- Architecture diagrams
- Component descriptions
- Integration points
- Technical constraints

**Typical Duration**: 1-3 days

---

### 5. Create Release Notes
**Description**: Document changes in a new release
**Input Required**:
- Feature list
- Bug fixes
- Breaking changes
- Known issues

**Output Produced**:
- Release notes document
- What's new section
- Upgrade instructions
- Breaking changes alert
- Known issues list

**Typical Duration**: 2-4 hours

---

### 6. Write Troubleshooting Guide
**Description**: Document common problems and solutions
**Input Required**:
- Common issues from support
- Error messages
- Solution steps
- System logs

**Output Produced**:
- Troubleshooting guide
- Problem/solution pairs
- Diagnostic steps
- When to contact support

**Typical Duration**: 4-8 hours

---

### 7. Create Tutorial
**Description**: Write step-by-step tutorial for specific task
**Input Required**:
- Task to teach
- Prerequisites
- Expected outcome
- Target skill level

**Output Produced**:
- Tutorial document
- Step-by-step instructions
- Screenshots/screen recordings
- Practice exercises
- Expected results

**Typical Duration**: 4-12 hours

---

### 8. Write Administrator Guide
**Description**: Document system administration procedures
**Input Required**:
- Installation process
- Configuration options
- Maintenance procedures
- Security settings

**Output Produced**:
- Administrator guide
- Installation instructions
- Configuration reference
- Maintenance procedures
- Security hardening

**Typical Duration**: 2-4 days

---

### 9. Update Existing Documentation
**Description**: Revise and update current documentation
**Input Required**:
- Current documentation
- Changes to document
- Deprecated features
- New information

**Output Produced**:
- Updated documentation
- Revision notes
- Updated screenshots
- Changed sections highlighted

**Typical Duration**: 1-8 hours

---

### 10. Create Diagrams
**Description**: Design technical diagrams and illustrations
**Input Required**:
- Diagram purpose
- Components to show
- Relationships
- Preferred style

**Output Produced**:
- Architecture diagrams
- Flow diagrams
- Sequence diagrams
- Network diagrams
- SVG/PNG exports

**Typical Duration**: 2-6 hours

---

### 11. Write Integration Guide
**Description**: Document how to integrate with external systems
**Input Required**:
- Integration points
- API specifications
- Authentication requirements
- Data formats

**Output Produced**:
- Integration guide
- Setup instructions
- API usage examples
- Authentication flow
- Sample code

**Typical Duration**: 1-2 days

---

### 12. Create Video Script
**Description**: Write scripts for tutorial videos
**Input Required**:
- Video topic
- Target duration
- Key points to cover
- Target audience

**Output Produced**:
- Video script
- Scene descriptions
- Narration text
- On-screen text notes
- Timing estimates

**Typical Duration**: 2-4 hours

---

## Documentation Priorities

### Immediate (P0)
- Critical bug workarounds
- Security-related updates
- Breaking change documentation
- Production incident guides

### High (P1)
- New feature documentation
- API documentation
- Release notes
- Getting started guides

### Medium (P2)
- Tutorial updates
- FAQ additions
- Diagram improvements
- Minor corrections

### Low (P3)
- Nice-to-have examples
- Additional tutorials
- Documentation polish
- Supplementary materials

## Quality Metrics

### Documentation Quality Indicators
- Clarity score (readability tests)
- Completeness (all features documented)
- Accuracy (technical review passed)
- Freshness (updated within 90 days)
- User satisfaction (feedback scores)
- Self-service rate (reduced support tickets)

### Success Metrics
- Documentation coverage: 100% of features
- User satisfaction: > 4/5 rating
- Support ticket reduction: 30%
- Time to find information: < 2 minutes
- Documentation bugs: < 5 per release
