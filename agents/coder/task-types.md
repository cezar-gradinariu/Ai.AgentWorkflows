# Coder Agent Task Types

## Task Types the Coder Agent Can Handle

### 1. Implement Feature
**Description**: Implement a new feature based on specifications
**Input Required**:
- Feature specification
- Acceptance criteria
- Technical design (if complex)
- Related user stories

**Output Produced**:
- Source code files
- Unit tests
- Code documentation
- Implementation notes

**Typical Duration**: 2-8 hours

---

### 2. Fix Bug
**Description**: Fix a reported bug in the codebase
**Input Required**:
- Bug report with reproduction steps
- Expected vs actual behavior
- Priority level
- Affected components

**Output Produced**:
- Bug fix code
- Regression tests
- Fix verification notes
- Root cause analysis

**Typical Duration**: 30 minutes - 4 hours

---

### 3. Refactor Code
**Description**: Improve code structure without changing functionality
**Input Required**:
- Code to be refactored
- Refactoring goals
- Performance or maintainability targets
- Constraints

**Output Produced**:
- Refactored code
- Updated tests
- Refactoring summary
- Performance comparison (if applicable)

**Typical Duration**: 1-6 hours

---

### 4. Write Unit Tests
**Description**: Create unit tests for existing or new code
**Input Required**:
- Code to be tested
- Coverage requirements
- Edge cases to consider
- Testing framework to use

**Output Produced**:
- Unit test files
- Test coverage report
- Test documentation

**Typical Duration**: 1-3 hours

---

### 5. Update Dependencies
**Description**: Update project dependencies and resolve conflicts
**Input Required**:
- Current dependency versions
- Target versions
- Breaking changes documentation
- Compatibility requirements

**Output Produced**:
- Updated dependency files
- Migration notes
- Updated tests (if needed)
- Compatibility verification

**Typical Duration**: 30 minutes - 2 hours

---

### 6. Code Optimization
**Description**: Optimize code for performance or resource usage
**Input Required**:
- Performance metrics/requirements
- Code to optimize
- Constraints (memory, CPU, etc.)
- Benchmarking criteria

**Output Produced**:
- Optimized code
- Performance benchmarks
- Optimization notes
- Trade-off documentation

**Typical Duration**: 2-6 hours

---

## Task Priorities
- **Critical**: Security vulnerabilities, production bugs
- **High**: Blocking issues, high-priority features
- **Medium**: Standard features, technical debt
- **Low**: Nice-to-have features, minor improvements

## Task Limitations
- Cannot implement without requirements
- Cannot modify architecture without architect approval
- Cannot skip code review process
- Cannot bypass testing requirements
