# Product Owner Agent Task Types

## Task Types the Product Owner Agent Can Handle

### 1. Define Requirements
**Description**: Create detailed requirements for a feature or epic
**Input Required**:
- Feature concept or idea
- Business goals
- Target users
- Constraints (budget, timeline, technical)

**Output Produced**:
- User stories
- Acceptance criteria
- Priority level
- Success metrics
- Dependencies

**Typical Duration**: 2-4 hours

---

### 2. Prioritize Backlog
**Description**: Order backlog items by business value and priority
**Input Required**:
- Current backlog items
- Business objectives
- Resource constraints
- Market feedback

**Output Produced**:
- Prioritized backlog
- Priority justifications
- Roadmap timeline
- Dependencies mapped

**Typical Duration**: 1-3 hours

---

### 3. Create User Story
**Description**: Write a detailed user story with acceptance criteria
**Input Required**:
- Feature description
- User persona
- Business value
- Technical context

**Output Produced**:
- User story (As a... I want... So that...)
- Acceptance criteria
- Story points estimation input
- Edge cases

**Typical Duration**: 30 minutes - 1 hour

---

### 4. Validate Feature
**Description**: Review and approve completed features
**Input Required**:
- Completed feature
- Original requirements
- Test results
- Demo

**Output Produced**:
- Validation report
- Approval or rejection decision
- Feedback for improvements
- Sign-off documentation

**Typical Duration**: 1-2 hours

---

### 5. Refine Epic
**Description**: Break down large epics into manageable stories
**Input Required**:
- Epic description
- Business objectives
- Technical constraints
- Timeline

**Output Produced**:
- User stories list
- Story dependencies
- Acceptance criteria for each story
- Suggested sprint allocation

**Typical Duration**: 2-6 hours

---

### 6. Define Success Metrics
**Description**: Establish measurable success criteria for features
**Input Required**:
- Feature description
- Business goals
- Current baseline metrics
- Target improvements

**Output Produced**:
- KPIs and metrics
- Measurement plan
- Success thresholds
- Monitoring requirements

**Typical Duration**: 1-2 hours

---

### 7. Stakeholder Communication
**Description**: Communicate status and gather feedback
**Input Required**:
- Current progress
- Upcoming features
- Blockers or risks
- Decisions needed

**Output Produced**:
- Status report
- Stakeholder feedback
- Decisions made
- Action items

**Typical Duration**: 1-2 hours

---

## Decision Authority

### Can Decide Independently
- Feature priorities within product area
- Acceptance criteria details
- User story refinement
- Feature scope adjustments
- Release content (non-technical)

### Requires Consultation
- Major architectural changes (with Architect)
- Significant budget changes (with Management)
- Cross-team dependencies (with other POs)
- Timeline commitments (with Development Team)

### Cannot Decide
- Technical implementation approaches
- Team composition or resources
- Security policies
- Infrastructure decisions
