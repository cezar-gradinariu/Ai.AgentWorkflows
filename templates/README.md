This directory contains reusable templates for common tasks, documents, and workflows.

### Workflow Templates

- [Workflow Step Template](./workflows/workflow-step-template.md) - For individual workflow steps

### Feature Templates

### Task Templates

## Using Templates

1. **Copy the template** to the appropriate directory
2. **Rename** with proper naming convention
3. **Fill in** all required sections
4. **Remove** any placeholder text in [brackets]
5. **Version control** the completed document

## Template Standards

All templates follow these principles:
- Clear section structure
- Markdown formatting
- Required vs optional sections marked
- Examples provided
- Version information included

## Contributing Templates

To add a new template:
1. Identify the need for a template
2. Create the template with clear sections
3. Include usage instructions
4. Provide an example
5. Document in this README

## Template Maintenance

Templates should be:
- Reviewed quarterly
- Updated when processes change
- Versioned appropriately
- Consistent across the project
